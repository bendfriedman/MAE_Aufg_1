# Mobile Anwendungsentwicklung – Übung 1

## Übersicht

Dieses Repository enthält die Lösungen zu **Übung 1** im Modul  
**Mobile Anwendungsentwicklung** an der Berliner Hochschule für Technik.

Ziel der Übung war es, grundlegende Konzepte der Android-Entwicklung zu erlernen, darunter:

- Erstellung von Android-Projekten
- Arbeiten mit TextViews und Buttons
- Eventhandling
- Benutzerinteraktion
- Einfache Berechnungen
- Layoutgestaltung

Die Aufgaben wurden sowohl mit **Jetpack Compose (deklarativ)** als auch mit  
**klassischen Views (imperativ)** umgesetzt.

---

## Inhalte der Übung

### Aufgabe 1 – Textdarstellung

Erstellung einer App zur Darstellung von Text mit verschiedenen Eigenschaften:

- Normaler Text
- Text in verschiedenen Farben
- Fett und kursiv formatierter Text
- Unterschiedliche Schriftgrößen
- Eigene Schriftart
- Text als Link

Umsetzung:

- Jetpack Compose
- Klassische Android Views

---

### Aufgabe 2 – Farbbalken-App

Entwicklung einer App, die mehrere farbige Balken auf dem Bildschirm darstellt.

Merkmale:

- Anzeige von 8 Farbbalken
- Verwendung von Layouts zur Anordnung der Elemente
- Umsetzung mit Compose und Views

---

### Aufgabe 3 – Temperaturumrechner

Erstellung einer App zur Umrechnung zwischen Celsius und Fahrenheit.

Funktionen:

- Eingabefeld für Temperaturwert
- Button für Umrechnung Celsius → Fahrenheit
- Button für Umrechnung Fahrenheit → Celsius
- Anzeige des Ergebnisses

Verwendete Formeln:


C = (F - 32) * 5 / 9
F = C * 9 / 5 + 32


---

### Aufgabe 4 – Taschenrechner

Implementierung eines einfachen Taschenrechners.

Funktionen:

- Eingabe von Zahlen (0–9)
- Grundrechenarten:

  - Addition
  - Subtraktion
  - Multiplikation
  - Division

- Ergebnisanzeige
- Löschen von Eingaben:

  - C (Clear)
  - CE (Clear Entry)
